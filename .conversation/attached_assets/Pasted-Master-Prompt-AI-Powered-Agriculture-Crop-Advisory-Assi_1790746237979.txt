10. Database Schema (Production SQL for PostgreSQL)
Execute the following schema to establish the relational data model:

SQL
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

CREATE TABLE crops (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    name VARCHAR(255) NOT NULL,
    description TEXT,
    optimal_temperature VARCHAR(100) NOT NULL,
    category VARCHAR(100) NOT NULL,
    compatible_soils TEXT[] DEFAULT '{}',
    is_active BOOLEAN DEFAULT true,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE advisory_requests (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    farmer_name VARCHAR(255) NOT NULL,
    phone VARCHAR(50) NOT NULL,
    location VARCHAR(255) NOT NULL,
    date_observed DATE NOT NULL,
    farm_size_acres DECIMAL(10, 2) NOT NULL,
    issue_description TEXT,
    status VARCHAR(50) DEFAULT 'Pending',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE admin_users (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
11. Row Level Security (RLS) / Data Isolation Rules
Public Access: SELECT queries on crops where is_active = true are permitted for all unauthenticated users.

Insert Access: Unauthenticated users may INSERT into advisory_requests (creating a log), but cannot SELECT, UPDATE, or DELETE existing requests.

Admin Access: Full CRUD access to all tables requires authentication middleware verifying an active admin session or valid JWT token.

13. Gemini SDK Setup & Server-Side Security
You must securely implement the @google/genai SDK on the Node.js backend. Never expose the API key to the React frontend.

JavaScript
import { GoogleGenAI } from '@google/genai';
import dotenv from 'dotenv';

dotenv.config();

// Initialize the Gen AI SDK
const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY });

// Reusable function for structured generation
export const generateAIResponse = async (prompt, systemInstruction, schema) => {
    try {
        const response = await ai.models.generateContent({
            model: 'gemini-2.5-flash',
            contents: prompt,
            config: {
                systemInstruction: systemInstruction,
                responseMimeType: "application/json",
                responseSchema: schema,
                temperature: 0.5 // Lower temp for more factual, agronomic accuracy
            }
        });
        return response.text; // Will be a JSON string matching the schema
    } catch (error) {
        console.error("Gemini API Error:", error);
        throw new Error("AI Generation failed");
    }
};

16. Zod Validation Requirements
All API inputs must be validated via Zod before processing.

JavaScript
import { z } from 'zod';

export const AdvisoryRequestSchema = z.object({
  farmerName: z.string().min(2, "Name must be at least 2 characters"),
  phone: z.string().min(10, "Valid phone number required"),
  location: z.string().min(2, "Location is required"),
  dateObserved: z.string().regex(/^\d{4}-\d{2}-\d{2}$/, "Must be YYYY-MM-DD"),
  farmSizeAcres: z.number().positive(),
  issueDescription: z.string().min(10, "Please describe the issue in detail")
});

export const CropSchema = z.object({
  name: z.string().min(2),
  description: z.string(),
  optimalTemperature: z.string(),
  category: z.string(),
  compatibleSoils: z.array(z.string()).optional()
});
